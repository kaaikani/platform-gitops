================================================================================
📋 USEFUL COMMANDS
================================================================================

# Check pod status
kubectl get pods -n {{ .Release.Namespace }}

# View Vendure logs
kubectl logs -f deployment/{{ include "vendure-stack.fullname" . }}-vendure -n {{ .Release.Namespace }}

# Restart Vendure
kubectl rollout restart deployment/{{ include "vendure-stack.fullname" . }}-vendure -n {{ .Release.Namespace }}

# Scale Vendure
kubectl scale deployment/{{ include "vendure-stack.fullname" . }}-vendure --replicas=3 -n {{ .Release.Namespace }}

# Upgrade the release
helm upgrade {{ .Release.Name }} ./vendure-stack -n {{ .Release.Namespace }}

# Uninstall
helm uninstall {{ .Release.Name }} -n {{ .Release.Namespace }}

================================================================================
⚠️  IMPORTANT NOTES
================================================================================

1. For PRODUCTION deployments:
   - Change all default passwords in values.yaml
   - Enable TLS/SSL for ingress
   - Set resource limits appropriately
   - Enable network policies
   - Use external secrets management (Vault, AWS Secrets Manager, etc.)

2. For HIGH AVAILABILITY:
   - Set vendure.replicaCount > 1
   - Enable vendure.autoscaling
   - Enable vendure.podDisruptionBudget
   - Configure mysql.architecture: replication
   - Configure redis.architecture: replication

3. For MONITORING:
   - Enable Grafana: grafana.enabled: true
   - Import recommended dashboards
   - Configure alerting rules
